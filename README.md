# Web3Drift

Web3Drift is a decentralized, blockchain-based data processing Node that enables real-time analytics through distributed, auto-scaling computations.

Web3Drift is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/Web3Drift.git`
2. `cd Web3Drift`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
